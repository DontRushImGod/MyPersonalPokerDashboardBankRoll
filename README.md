 MyPersonalPokerDashboardBankRoll Web App

This project is a personal Poker Bankroll Management web application designed to help poker players track, organize, and manage their bankroll in a structured and disciplined way.
The main goal of this website is to provide players with a clear overview of their poker finances, allowing them to make better decisions based on real data rather than intuition.

Concept

Bankroll management is one of the most important aspects of long-term success in poker. This application was created to simplify that process by offering a centralized platform where users can:
Track their bankroll over time
Register poker sessions (cash games or tournaments)
Monitor profits, losses, and win rates
Analyze performance by game type, stakes, or date
Maintain financial discipline and reduce risk
Instead of using spreadsheets or manual notes, this website aims to offer a more intuitive and user-friendly solution tailored specifically for poker players.

Purpose

This project is primarily focused on personal use and learning, combining web development with a real-world poker use case. It can be extended in the future with additional features such as statistics dashboards, charts, multi-currency support, or user authentication.

Disclaimer

This application does not provide gambling advice or promote irresponsible gambling. It is purely a financial tracking and organizational tool intended to encourage responsible bankroll management.
